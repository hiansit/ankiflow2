# Ankiflow 2 クイックスタートパック (QuickStart Pack)

本フォルダは、Webアプリ「**Ankiflow 2**」を初めて利用するユーザーのための、公式スタートガイドPDFおよび5科目のサンプル教材セットです。

---

## 📂 フォルダ構成

```
quickstart_pack/
├── Ankiflow2_QuickStart_Guide.pdf  # 📕 クイックスタートガイド本体（全6ページ・画面解説付きPDF）
├── README.md                       # 案内ドキュメント（本ファイル）
└── materials/                      # 📚 各種科目用サンプル教材（CSV形式・各20項目）
    ├── 01_traditional_chinese_20.csv  # 繁体字中国語（台湾華語・注音・ピンイン・音声対応）
    ├── 02_english_words_20.csv        # 重要英単語（IPA発音記号・日本語訳）
    ├── 03_english_idioms_20.csv       # 重要英熟語（イディオム・実践例文）
    ├── 04_japanese_history_20.csv     # 日本史重要年号（出来事・時代背景解説）
    └── 05_chemical_elements_20.csv    # 化学元素記号（記号・元素名・原子番号・分類）
```

---

## 🚀 すぐに体験する手順

1. **アプリを開く**:
   - 公開Webアプリ: [https://hiansit.github.io/ankiflow2/](https://hiansit.github.io/ankiflow2/)
2. **ガイドを読む**:
   - `Ankiflow2_QuickStart_Guide.pdf` を開き、第2章「ローカルDBの作成・保存フロー」に従ってPC上に `.db` を作成します。
3. **サンプル教材を取り込む**:
   - `materials/` フォルダ内のCSVファイルをブラウザの「➕ 教材追加」画面にドラッグ＆ドロップします。
4. **学習を開始する**:
   - 通常のフラッシュカード学習、または「🎧 自動連続再生（耳学習）」モードでハンズフリーの学習を体験してください。
